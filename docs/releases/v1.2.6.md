### 작업 표시줄 메뉴 · 이름 정리 · 화면 다듬기

- 작업 표시줄의 RamCalendar 아이콘을 오른쪽 클릭하면 **업데이트 확인 · 설정 열기 · 완전히 종료**가 나와요
- 업데이트 확인을 직접 누르면 결과를 창으로 알려 주고, 새 버전이 있으면 **지금 다시 켜기**로 바로 바꿀 수 있어요
- 앱 이름을 **RamCalendar**로 붙여 썼어요 (RamClock · RamSpirit과 같은 모양). 로그인과 설정은 그대로 이어져요
- 위쪽 버튼 아이콘의 크기와 굵기, 가운데 위치를 하나로 맞췄어요
- 일정이 많은 날만 글씨가 작아지던 문제를 고쳤어요. 이제 모든 칸의 글씨 크기가 같고, 넘치는 일정은 오른쪽 위 **+N**으로 접혀요

---

**처음 설치한다면** [최신 버전](https://github.com/dpfkadpfka/yeram-calendar/releases/latest)의 Assets에서 `RamCalendar-Setup-버전.exe`를 받아 실행 → "Windows의 PC 보호"가 뜨면 **추가 정보 → 실행**

**이미 쓰고 있다면** 자동으로 업데이트돼요.

설치 · 처음 설정 · 자주 묻는 질문은 [README](https://github.com/dpfkadpfka/yeram-calendar#readme)에 있어요.
